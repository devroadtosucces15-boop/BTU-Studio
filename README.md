# BTU Studio

Herramienta educativa de estimación térmica en español de México. Diseño móvil, accesibilidad, navegación por progreso, gráficos, parámetros editables y proyectos JSON.

## Privacidad

Los datos se guardan en el almacenamiento local del navegador (`localStorage`). No se transmiten a GitHub ni a una base de datos de usuarios. Exporta los proyectos JSON para respaldarlos o transferirlos. Borrar los datos del sitio puede eliminar proyectos locales.

## PWA

Safari → Compartir → Añadir a pantalla de inicio. La compatibilidad y el uso del icono pueden variar según la versión de iOS.

## Alcance técnico

Es una estimación simplificada, no un cálculo ACCA Manual J. Temporada y temperatura de diseño se registran como contexto sin introducir ajustes automáticos sin respaldo técnico. Los coeficientes se pueden editar. No se ha integrado autenticación ni sincronización de cuentas.
